# Netflix Customer Churn Analysis

## Project Overview
An end-to-end data analytics project focused on analysing customer churn, understanding customer behaviour, and identifying patterns that may affect customer retention.

## Business Objectives
- Analyse customer churn rate.
- Identify customer segments with higher churn.
- Understand subscription and payment patterns.
- Generate actionable business insights.

## Tools & Technologies
- **Excel:** Data cleaning, PivotTables, and KPI analysis.
- **PostgreSQL (SQL):** Data analysis using aggregations, CASE WHEN, subqueries, CTEs, and window functions.
- **Power BI:** Interactive dashboard development and data visualisation.
- **AI Tools:** AI-assisted SQL development, troubleshooting, and analytical guidance.

## Project Workflow
1. **Excel:** Data cleaning, preparation, and exploratory analysis.
2. **SQL:** Customer churn analysis using PostgreSQL.
3. **Power BI:** Dashboard creation and visualisation.
4. **AI Assistance:** Used AI tools to support problem-solving and analytical workflows.

## Key Insights
- Overall customer churn rate.
- Churn patterns across subscription types.
- Customer demographics and behaviour.
- Payment-related churn patterns.

## Conclusion
This project demonstrates an end-to-end analytics workflow combining Excel, SQL, Power BI, and AI-assisted analysis to understand customer churn and support data-driven decisions.

**Domain:** Customer Analytics | **Project Type:** End-to-End Data Analytics
